# Moj Prozor — landing page redesign

Static redesign concepts for [mojprozor.rs](https://mojprozor.rs/).

| Page | File | Direction |
| --- | --- | --- |
| V1 | `index.html` (`/`) | Elegant + SaaS: 3D opening-sash hero, live window configurator, savings calculator, profile anatomy |
| V2 | `v2.html` (`/v2`) | Lighter, Apple-style product page with the same configurator and calculator |

No build step: open `index.html` in a browser, or import the repo into Vercel (`vercel.json` enables clean URLs).

## Notes

- Prices, Uw/Rw values and energy prices in the configurator and calculator are placeholder models; confirm them before going live.
- Forms (quote request, newsletter) validate input but are not connected to any backend.
- Imagery comes from mojprozor.rs, plus four images generated with Higgsfield (`img/interior.jpg`, `img/profile.jpg`, `img/house.jpg`, `img/handle.jpg`).
